Healthcare Connector
Project Overview
Healthcare Connector is a healthcare authorization management platform that enables Providers, Payers, and Administrators to manage patient authorization requests efficiently. The application is built using Angular 22 and integrates with Spring Boot REST APIs secured using JWT Authentication.
